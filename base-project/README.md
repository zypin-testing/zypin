# Testing Project

A testing project powered by Zypin.

## Getting Started

```bash
npm install                    # Install dependencies
npm run list                   # See available templates
npm run scaffold playwright-basic  # Add a testing template
npm test                       # Run tests
```

## Commands

- `npm run scaffold <template>` - Add a testing template
- `npm run list` - Show available templates (alias: `npm run templates`)
- `npm test` - Run tests
